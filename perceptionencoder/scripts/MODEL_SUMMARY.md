## High-level architecture

Diagram: [`pe_core_architecture.svg`](pe_core_architecture.svg)

This is a **CLIP dual-encoder**: one vision tower + one text tower that project
into a shared **1024-d** embedding space, plus a scalar `logit_scale` for
contrastive scoring.

```
Image ──► visual.*  ──► 1024-d  ─┐
                                 ├─ cosine / (logit_scale * dot)
Text  ──► transformer.* + … ──► 1024-d  ─┘
```

Matches the published config: **L/14 @ 336px**, width **1024**, **24** layers
each side, output dim **1024**, text context length **32**.

## How this project uses it

1. `pe.CLIP.from_config("PE-Core-L14-336", pretrained=True)` builds the empty
   dual encoder and `load_state_dict`s these 601 tensors.
2. **Index:** frames → `encode_image` → mean-pool → L2-norm chunk vector.
3. **Search:** NLQ → `encode_text` → L2-norm → cosine vs chunk vectors.

Embedding dim used by videosearch: **1024**.
